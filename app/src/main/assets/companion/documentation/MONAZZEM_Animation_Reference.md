# مرجع حركات رفيق MONAZZEM ثلاثي الأبعاد
# MONAZZEM Animation Reference

**الملف:** `MONAZZEM_Companion.glb` (1,375,416 بايت) — glTF 2.0
**معدل الإطارات:** 24 fps لكل الحركات.
**التحقق:** كل حركة قناة `rotation` مستقلة لكل عظم + قناة `weights` واحدة للـ morph targets؛ الأسماء كما في جدول glTF `animations`. قيس تباين الدوران داخل كل حركة (انظر تقرير الإنتاج §5.3) للتأكد من الاستقلال.

## الحركات الخمس

| الاسم (كما في الـ GLB) | المدة | الإطارات | النوع | الوصف | الـ morph المستخدم |
|---|---|---|---|---|---|
| `IDLE` | **5.0 ث** | 1–120 | loop سلس | تنفس خفيف (صدر ±0.035 راد)، إيماءة رأس خفيفة يمين/يسار، رمشان (إطارات 28–34 و82–88)، ابتسامة خفيفة 0.15–0.2 | `Closed` (رمش)، `Smile` 0.15 |
| `GREETING` | **2.5 ث** | 1–60 | one-shot → محايد | ابتسامة كاملة + الذراع اليمنى ترفع جانبيًا (~83°) وتلوّح 4 مرات، إمالة رأس خفيفة، عودة للوضع المحايد | `Smile` 1.0، `Happy` 0.6 |
| `ENCOURAGEMENT` | **2.5 ث** | 1–60 | one-shot → محايد | إيماءة رأس مرتين (للأسفل)، الذراع اليمنى للأمام مع ثني الكوع (~52°+63°، قبضة تشجيع عند الصدر)، عودة للمحايد | `Encouraging` 1.0، `Smile` 0.7 |
| `ACHIEVEMENT` | **3.0 ث** | 1–72 | one-shot → محايد | الذراعان معًا لأعلى على شكل V (~115° لكل ذراع)، صدر مرفوع قليلًا ورأس للأعلى، ابتسامة فرح، عودة للمحايد | `Happy` 1.0، `Achievement` 1.0 |
| `THINKING` | **4.0 ث** | 1–96 | loop سلس | إمالة رأس ثابتة (~9–11°)، اليد اليمنى عند الذقن (ذراع أمامية + كوع مثني)، حركة رأس طفيفة، تعبير تأمل | `Thinking` 1.0 |

**ملاحظات الـ loop:** في `IDLE` قيمة الإطار 120 = قيمة الإطار 1 (كل الدورانات 0، `Smile` ‏0.15)؛ وفي `THINKING` قيمة الإطار 96 = قيمة الإطار 1 (إمالة الرأس 0.16 راد، الذراع اليمنى ثابتة للأمام). الحركات الـ one-shot الثلاث تنتهي كلها بالوضع المحايد (دوران 0 وmorph ‏0) لتنتقل بسلاسة إلى `IDLE`.

## الـ Rig (22 مفصلًا)

```
root → pelvis → spine → chest → neck → head
                 ├─ shoulder.L/R → upper_arm.L/R → forearm.L/R → hand.L/R → finger.L/R
                 └─ thigh.L/R → shin.L/R → foot.L/R
```

- الـ root في الأصل (0,0,0)، ارتفاع الشخصية 1.76 م (قمة الرأس 1.76 م، القدم عند 0).
- الـ skinning: مجموعات رؤوس حسب الجزء (rigid، وزن 1.0) — انظر تقرير الإنتاج §7.2.
- أقصى تأثير: 4 مفاصل لكل رأس (glTF `maxInfluences: 4`)، فعليًا 1 لكل رأس.

## تعابير الوجه (morph targets — 9 + Basis)

| الاسم | ما يفعله | أقصى إزاحة موضعية (م) |
|---|---|---|
| `Smile` | زاويتا الفم لأعلى | 0.010 |
| `Happy` | ابتسامة + تضييق العينين + رفع الحاجبين | 0.010 |
| `Surprised` | فم أوسع + حاجبان لأعلى + عينان أوسع | 0.021 |
| `Thinking` | الفم يميل لجهة + الحاجب الأيسر لأعلى | 0.010 |
| `Encouraging` | ابتسامة خفيفة + حاجبان لأعلى من الداخل | 0.010 |
| `Achievement` | كـ Happy (ابتسامة فرح كاملة) | 0.010 |
| `Blink_L` / `Blink_R` | إغلاق عين واحدة (تسطيح كرة العين) | 0.027 |
| `Closed` | إغلاق العينين معًا | 0.027 |
| `Basis` | محايد (مرجع، بلا إزاحة) | 0 |

جميع القيم مقاسة من الـ GLB نفسه (min/max لوصولات الـ POSITION في الـ morph targets).

## طريقة التحقق (لمن يعيد الفحص)

```bash
# 1) بنية الـ GLB والحركات
python3 -c "from pygltflib import GLTF2; g=GLTF2().load('MONAZZEM_Companion.glb'); print([a.name for a in g.animations])"
# 2) تحقق مستقل (morph + skinning + عزل الحركات)
python3 scripts/verify_glb.py MONAZZEM_Companion.glb
# 3) مدقق Khronos الرسمي (0 أخطاء متوقعة)
node /tmp/validate_gltf.js MONAZZEM_Companion.glb
# 4) إعادة الاستيراد في Blender (armature + shape keys + actions)
blender --background --python /tmp/reimport.py
```

## ربط الحركات بأحداث التطبيق (مقترح، من المواصفة §12 و§17 — لم يُنفَّذ بعد)

| حدث التطبيق | الحركة |
|---|---|
| الحالة الافتراضية على الرئيسية | `IDLE` |
| فتح التطبيق | `GREETING` ثم عودة لـ `IDLE` |
| إكمال مهمة | `ACHIEVEMENT` ثم عودة لـ `IDLE` |
| المستخدم يحتاج تشجيعًا | `ENCOURAGEMENT` ثم عودة لـ `IDLE` |
| حالة تفكير/معالجة | `THINKING` (loop حتى انتهاء المعالجة) |

واجهة التحكم المقترحة (Kotlin، من المواصفة §17): `playIdle() / greet() / encourage() / celebrateAchievement() / think() / setVisible() / setEnabled() / release()` — التنفيذ على نسخة MONAZZEM في مهمة منفصلة.
